# Abyss Manager
> Made by Abyss, join today! -> https://discord.gg/9YMRP6gCY

1. How to set up
   - Install Node.js 22 (This is easy, so I won't explain how to use it)
   - Once Node is installed, open the terminal in the project folder
   - Run ```npm install discord.js```
   - Once installed, run the bot with ```node index.js```. If you get an error, you probably didn't set the token and other information in index.js, so do that.
